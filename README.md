# 🛒 Online Store

Full-stack e-commerce platform with separate **Client** and **Admin** panels.  
Built to demonstrate scalable architecture, authentication, product management, and order handling.  

---

## 🚀 Tech Stack
- **Frontend (Client):** React, Redux Toolkit, TailwindCSS  
- **Frontend (Admin):** React, Material-UI  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Authentication:** JWT  

---

## ✨ Features
- 🔐 User authentication & authorization (JWT)  
- 👤 Client panel for browsing products & making orders  
- 🛠 Admin panel for managing products, categories, and orders  
- 📦 REST API for frontend-backend communication  
- ⚡ State management with Redux Toolkit
